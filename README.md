# 🌐 Projeto Web com HTML, Bootstrap e JavaScript

Este é um site simples desenvolvido com **HTML**, **Bootstrap** e **JavaScript Vanilla**.

## 📁 Estrutura do Projeto

- `index.html` — Estrutura da página com links para o CDN do Bootstrap
- `style.css` — Código CSS para interações estilização e responsividade

## 🎨 Estilo com Bootstrap

O estilo visual do site foi feito utilizando **Bootstrap 5**, por meio de CDN.

## ▶️ Como Rodar o Projeto

Para executar o projeto localmente, é recomendado utilizar a extensão **Live Server** no VS Code.

### Passos:

1. Abra o projeto no [Visual Studio Code](https://code.visualstudio.com/)
2. Instale a extensão **Live Server**:
   - Vá até a aba de extensões (`Ctrl+Shift+X`)
   - Procure por `Live Server` e instale a extensão criada por **Ritwick Dey**
3. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"**
4. O navegador abrirá automaticamente com o projeto rodando localmente

## 🚀 Tecnologias Utilizadas

- HTML5
- Bootstrap 5 (via CDN)
- JavaScript Vanilla
- Live Server (VS Code Extension)
